## 6. Data model required for the Curriculum Atlas

Every source and derived syllabus item should retain:
- `source_id`, issuer, official/secondary status, source URL, document title, memo/reference number, publication date, retrieval date, content hash, page count, file type, extraction method, reviewer and verification status.
- `cohort_id`, academic session, intake year, class, examination year, board, group, subject, paper, subject code, version/effective date.
- `unit_or_chapter_id`, canonical title (Bangla and English where applicable), source-native numbering, lesson/topic IDs, prerequisite links and textbook page references.
- Rights status and allowed use (metadata only, link-only, licensed ingestion, teacher-authored derivative, public-domain/open licence).

Do not conflate a textbook title list with a prescribed syllabus; keep each document type distinct.
